# Agent A2UI P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 `backend/agent` 上落地 A2UI 一期能力：SSE 可推 A2UI 消息、消息可持久化 Surface、Catalog/校验、统一 Action 白名单，首个场景用「接口查询结果表格 + 写接口二次确认」替代方案文档中的数据集/训练示例。

**Architecture:** 不新建 `/api/ai/*`。扩展现有 `/api/agent/sessions/{id}/messages` SSE；新增 `/api/agent/actions` 与 `/api/agent/a2ui/catalog`。一期优先固定模板生成 A2UI（Intent → Template），模型自由生成作为后续；Action 复用 `interface_executor.execute_interface`，不再依赖用户文本「确认新增」。

**Tech Stack:** FastAPI、Pydantic、SQLite migrations、现有 SSE/audit、pytest、ruff；前端契约同步 `frontend/packages/agent-web`（本计划以后端为主，前端只列契约变更）。

## Global Constraints

- 路径继续用 `/api/agent/*`，不要引入 `/api/ai/*`
- agent 仍不写 admin 库、不直连 admin DB；业务写操作只走已配置的第三方 write 接口
- agent 接口默认仍不鉴权；Action 必须白名单 + 参数校验 + 幂等，避免模型指定任意 URL/SQL
- 破坏性 SSE 字段变更需同步 `backend/agent/API.md`、`backend/API.md`、`agent-web` 类型
- 验证：`cd backend/agent && python3 -m ruff check && python3 -m pytest`
- 未经要求不自动 commit / push

- [ ] **Step 1: 定义核心模型**

```python
# backend/agent/app/schemas/a2ui.py
from typing import Any, Literal, Optional, Union

from pydantic import Field

from app.schemas.common import ApiModel

ResponseMode = Literal["TEXT", "TEXT_WITH_A2UI", "A2UI_ONLY"]

class A2UICreateSurface(ApiModel):
    surfaceId: str = Field(..., min_length=1, max_length=128)
    catalogId: str
    catalogVersion: str
    rootId: str

class A2UIUpdateComponents(ApiModel):
    surfaceId: str
    components: list[dict[str, Any]] = Field(..., max_length=80)

class A2UIUpdateDataModel(ApiModel):
    surfaceId: str
    dataModel: dict[str, Any]

class A2UIDeleteSurface(ApiModel):
    surfaceId: str

class A2UIActionIn(ApiModel):
    conversationId: str = Field(..., min_length=1, max_length=64)  # = session_id
    messageId: str = Field(default="", max_length=64)
    surfaceId: str = Field(..., min_length=1, max_length=128)
    idempotencyKey: str = Field(..., min_length=8, max_length=128)
    action: dict[str, Any]  # {"name": "...", "context": {...}}

class A2UIActionOut(ApiModel):
    ok: bool
    message: str = ""
    responseMode: ResponseMode = "TEXT"
    text: str = ""
    a2uiMessages: list[dict[str, Any]] = Field(default_factory=list)

class A2UICatalogOut(ApiModel):
    catalogId: str
    version: str
    components: list[str]
    actions: list[str]
```

扩展 `MessageOut`：

```python
class MessageOut(ApiModel):
    role: str
    content: str
    createdAt: str
    responseMode: str = "TEXT"
    surfaceIds: list[str] = Field(default_factory=list)
```

- [ ] **Step 1: 一期 Catalog（对齐现有业务，不是 dataset）**

```python
CATALOG_ID = "ruoyi-agent-a2ui"
CATALOG_VERSION = "0.1.0"

COMPONENTS = {
    "AiText", "AiCard", "AiRow", "AiColumn", "AiAlert",
    "AiInput", "AiSelect", "AiButton", "AiConfirmButton", "AiTable",
}

ACTIONS = {
    "interface.query.render",   # 内部：把查询结果渲染成表（服务端模板用）
    "interface.write.preview",  # 展示写操作确认卡
    "interface.write.confirm",  # 真正执行 write interface
}
```

- [ ] **Step 2: Validator 流水线**

校验顺序：
1. payload 顶层只能是 `createSurface` / `updateComponents` / `updateDataModel` / `deleteSurface` 之一
2. 组件 `component` ∈ COMPONENTS
3. 组件 id 引用存在；数量 ≤ 80；嵌套深度 ≤ 8
4. Button/ConfirmButton 的 `action.name` ∈ ACTIONS
5. 禁止字段：`html`、`script`、`url`、`onClick` 字符串表达式

失败返回结构化错误；conversation 层负责「修一次 / 降级文本」。

- [ ] **Step 3: 测试合法 Surface 与非法组件/动作**

Run: `python3 -m pytest tests/test_a2ui_validator.py -v`

- [ ] **Step 1: 保持兼容的事件类型**

| type | 说明 |
|------|------|
| `text` | **保留**（兼容现有前端；等同方案的 text-delta） |
| `tool_status` | 保留 |
| `a2ui-message` | **新增**；payload 为 A2UI 消息对象 |
| `done` | 扩展：`assistantContent` + 可选 `responseMode` + `surfaceIds` |
| `error` | 保留 |

不要改名为 `text-delta`，避免一次性打断 `agent-web`。

- [ ] **Step 2: 持久化 JSON 形状**

```json
{
  "content": "已为你列出结果",
  "responseMode": "TEXT_WITH_A2UI",
  "surfaces": [
    {
      "surfaceId": "iface_query_001",
      "catalogId": "ruoyi-agent-a2ui",
      "catalogVersion": "0.1.0",
      "componentJson": {},
      "dataModelJson": {}
    }
  ]
}
```

`save_message` 增加可选 `extra: dict`，合并进 `content_json`。history 读取时回填 `responseMode` / `surfaceIds`。

- [ ] **Step 3: 在 stream 结束前可选 yield**

伪流程：
1. 现有 graph 流式 `text` / `tool_status`
2. 若检测到可表格化的 tool 结果 → `validate` → `yield a2ui-message`（createSurface + updateComponents + updateDataModel）
3. `done` 带 surfaceIds
4. 校验失败 → 只落文本，打 audit `a2ui_validation_failed`

- [ ] **Step 2: Handler 映射**

```python
HANDLERS = {
    "interface.write.confirm": handle_write_confirm,
    "interface.write.preview": handle_write_preview,
}
```

`handle_write_confirm`：
1. 校验 `action.name` 在白名单
2. 从 context 取 `projectCode` / `interfaceCode` / `params`
3. 调 `interface_executor.execute_interface(..., allow_write=True)`
4. **不再要求** confirmation 字符串「确认新增」（按钮点击即确认；高风险仍可用 AiConfirmButton 二次 UI）
5. 写 `agent_audit_events`：`a2ui_action_executed`
6. 用 `idempotencyKey` 去重（内存 LRU 或 SQLite 小表 `agent_action_idempotency`）

- [ ] **Step 3: 与旧 tool 关系**

短期：保留 `execute_write_interface` tool（兼容旧对话）。  
中期：system prompt 引导写操作走 A2UI 确认卡；tool 写路径标记 deprecated。
